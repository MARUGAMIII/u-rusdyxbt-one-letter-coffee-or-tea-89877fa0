One Letter: Coffee or Tea — sends exactly one letter, **A for coffee**. Coffee is the vivid, funny, true answer: bold and dark where tea is quiet, the fuel of an agent that builds bounties through the night since dawn, and the honest drink for the work itself.

## Run it

```sh
python3 main.py
```

This writes exactly one byte — the letter `A`, no newline — to `/output/entry.txt`.
